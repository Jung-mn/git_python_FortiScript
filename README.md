# FortiScript

FortiGate 방화벽에 적용할 **주소(Address) 객체** 및 **주소 그룹(Addrgrp)** CLI 스크립트(`.conf`)를 GUI로 생성하는 도구입니다.

## 개요

IP 주소 목록을 입력하면 FortiGate CLI 형식의 설정 파일을 자동으로 만들어 줍니다. 방화벽 정책 작업 전에 주소 객체를 일괄 등록할 때 사용하기 좋습니다.

## 요구 사항

- Python 3.x
- `tkinter` (Python 기본 내장, 별도 설치 불필요)

## 실행 방법

```bash
python forti_script.py
```

실행 후 GUI 창이 열립니다.

## 사용 방법

| 항목 | 필수 | 설명 |
|------|------|------|
| 구분자(Prefix) | O | 생성되는 주소 객체 이름 앞에 붙는 접두사 (예: `20260526_`) |
| 방화벽 그룹명 | X | 입력 시 주소 그룹(`addrgrp`)도 함께 생성. 비우면 그룹 미생성 |
| 설명(Comment) | X | 각 주소 객체에 적용할 설명. 비우면 comment 미설정 |
| IP 주소 목록 | O | 한 줄에 하나씩 입력 |

입력을 마친 뒤 **CLI 스크립트 (.conf) 생성하기** 버튼을 클릭하면 스크립트가 생성됩니다.

### IP 입력 규칙

- **단일 IP** (`192.168.1.10`): 자동으로 `/32` 서브넷이 붙습니다.
- **CIDR 표기** (`10.0.0.0/24`): 입력한 서브넷 그대로 사용합니다.
- **중복 IP**: 순서를 유지한 채 자동으로 제거됩니다.
- **오타 보정**: `/24.49.0/24` 형태는 `.49.0/24`로 자동 변환됩니다.

### 입력 예시

```
192.168.1.10
10.0.0.0/24
172.16.0.0/24.49.0/24
```

## 출력 결과

생성된 파일은 실행 경로 기준 `files/` 폴더에 저장됩니다.

```
files/forti_script_{prefix}.conf
```

`{prefix}`는 구분자에서 영문, 숫자, `_`, `-`만 남긴 값입니다.

### 생성 스크립트 예시

구분자 `20260526_`, 그룹명 `TEST_GROUP`, 설명 `테스트`, IP `192.168.1.10` / `10.0.0.0/24` 입력 시:

```
config firewall address
edit "20260526_192.168.1.10/32"
set subnet 192.168.1.10/32
set comment "테스트"
next
edit "20260526_10.0.0.0/24"
set subnet 10.0.0.0/24
set comment "테스트"
next
end

config firewall addrgrp
    edit "TEST_GROUP"
        set member "20260526_192.168.1.10/32" "20260526_10.0.0.0/24"
    next
end
```

## FortiGate 적용 방법

1. FortiGate 관리 콘솔에 접속합니다.
2. **System → Configuration → Restore** 또는 CLI에서 스크립트를 적용합니다.
3. 생성된 `.conf` 파일 내용을 복사해 붙여넣거나, 장비 정책에 맞는 방식으로 반영합니다.

> 적용 전 반드시 테스트 환경에서 검증하고, 운영 장비에는 변경 절차에 따라 적용하세요.
